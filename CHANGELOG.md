# Changelog

This project follows [Semantic Versioning](https://semver.org). Tags are never moved.

## [1.0.0] - 2026-11-25

Initial standalone release for Paper, compatible with the ANX Network API shipped by anx.run 1.5.0.

### Added
- Pairing, heartbeat, aggregate telemetry, MOTD verification and diagnostics.
- Optional Geyser/Floodgate accounting and configurable vote rewards.
- Bounded ordered retry queue and permanent stop after an agent credential is refused.
- Pinned ANX Network Bridge Core, reproducible Gradle build, integration tests and release checksums.
